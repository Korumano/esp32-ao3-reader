# esp32-ao3-reader
Portable hand-held AO3 reader powered by esp32-s3 with an oled display and 6 pushbuttons


HELLO WORLD!!
this is a hackclub project :))

ESP32 AO3 READER :D

an ao3 scroller using:

-esp32 s3
-oled display
-6 pushbuttons(up, down, left, right, select, back)
-lithium battery(with usb c charging module tp4056)
-all soldered on a perfboard

You can scroll on archiveofourown.org (ao3.org) website fanfiction, anywhere wherever you got wifi

I'm trying my best to make the battery life as efficient as I possibly can.

It's using an on-screen keyboard, which you type using the 5 (respectively 6) phyisical buttons, and filter through tags(can add multiple 1+), word count, and creator name.

perfboard supremacy over breadboard


I'm trying my best to make it compact with the battery and might add a 3d-printed case or a cardboard one.

In the on screen sidebar menu you can toggle wi-fi/disconnect/connect, save specific posts, shut off screen(stand-by mode where it shuts off wifi and screen and wakes both up when any button is clicked)
